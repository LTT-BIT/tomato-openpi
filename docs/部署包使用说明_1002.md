# 1002 子任务部署包

本包包含 1002 详细英文指令版本的最终 19999 checkpoint：完整推理参数、配套归一化、
PaliGemma tokenizer、对应 Git 版本代码、依赖锁文件及四条英文 prompt。
这不是仅包含 LoRA adapter 的文件，无需额外复制 pi05_base。
不包含训练数据、优化器状态、虚拟环境、CUDA 驱动或 Python 依赖安装包。

## 解压与安装

使用支持 ZIP64 的 unzip 或 7-Zip。依赖安装需要网络以及兼容 NVIDIA GPU/CUDA 的 Linux 环境。

```bash
unzip pi05_1002_subtasks_19999_deploy.zip
cd pi05_1002_subtasks_19999/code
GIT_LFS_SKIP_SMUDGE=1 uv sync --frozen --python 3.11
GIT_LFS_SKIP_SMUDGE=1 uv pip install -e .
JAX_PLATFORMS=cuda .venv/bin/python scripts/serve_1002_bundle.py --port 8000
```

启动入口自动使用包内 checkpoint、assets 和 tokenizer，不依赖原训练机 `/home/descfly` 的数据路径。
远程已有相同依赖时可使用对应 Python 环境，但必须加载本包 code 中的 openpi 源码。
包内 `manifest.json` 记录源代码 commit 和权重、归一化、tokenizer 的 SHA-256。
ZIP 旁的 `.sha256` 文件用于传输后执行 `sha256sum -c 文件名.zip.sha256` 校验。

## 调用与动作约定

`prompts.json` 保存四条精确英文指令，按任务 ID 0–3 选择，随每次请求的 `prompt` 发送。
第二任务将番茄移到中央并保持握住，不能松手。任务完成判断和 prompt 切换由外部执行端负责。
三路输入键为 `observation/image`、`observation/left_wrist_image`、`observation/right_wrist_image`，
状态键为 `observation/state`。支持原始 108 维状态或已按模型顺序排列的 54 维位置。
模型位置/输出动作顺序为左臂7、左手20、右臂7、右手20。返回的双臂动作已恢复绝对量。
动作轨迹为 50 帧、30 Hz。策略服务不包含机器人硬件驱动或自动执行程序。
