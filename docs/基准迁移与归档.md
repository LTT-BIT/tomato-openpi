## 保留与排除

保留共享模型、JAX/PyTorch 训练、数据加载、数据校验、归一化、采样、恢复、本体变换、锁文件、许可及 LoRA v1/全参 v1 分层基准。openpi-client 仅保留训练图像工具。数据格式转换与合并由独立数据仓库负责，当前训练树已移除 FR3/Wuji、Aloha、DROID、Libero 的数据格式转换脚本及 FR3/Wuji 合并脚本；原始采集对照校验的只读辅助代码独立保留，不依赖被删除的转换模块。模型 checkpoint 的 JAX/PyTorch 格式转换不属于数据格式转换，继续保留。

移除当前树中的 deploy、websocket 服务与客户端运行时、执行器、部署打包脚本、非训练实验、机器人/仿真运行示例、硬件子模块和根目录独立 norm_stats 文件。本体输入/输出转换和 checkpoint 内统计保存属于训练框架，继续保留。

本机 Git 忽略的数据、权重、日志、缓存和环境不删除、不提交。直接复制工作区可能带上这些文件，导出源码快照应使用 git archive HEAD；直接推送分支会带旧历史，纯训练历史通过快照初始化。

## 归档

原训练教程、参数和交接文档移入 docs/archive/baselines/；其他训练相关历史说明移入 docs/archive/legacy/。历史文本保留原记录，附归档提示并修复仍存在文件的链接；旧路径和推理示例属于当时上下文，不作为新仓库操作入口。归档清单记录原文和当前哈希，部署专用文档回原分支查询。

后续精简已删除 training_baseline/ 及原路径跳转页、历史辅助程序，活动配置只有 training_configs/。删除前从原 v2/v3 配置生成 tests/fixtures/baselines/ 静态快照，记录源 commit、原文件 SHA-256 和路径占位规则，回归测试不再依赖旧代码。原全参数据/采样检查迁入新测试，模型冻结检查由现有双方案测试覆盖。源码审计清单随之改变，此精简版本不用于严格续训精简前实验。

当前入口为 [训练使用说明](训练使用说明.md) 和 [多人开发 README](多人开发README.md)。新增记录区分准备完成与训练完成，记录数据来源、配置、实验名、统计和英文 prompt。

标准分层入口使用 JAX。保留的 scripts/train_pytorch.py 是独立实现，尚未接入本入口的 epoch_shuffle/独立种子恢复契约及 W&B 分段日志方案；不用于照本教程恢复 v1 实验。本轮验证和新电脑训练教程均针对统一 JAX 入口。

## 数据与实验合并管理

用户选择每人完整管理自己的实验，删除 training_configs/datasets/。Dataset 公共结构和路径辅助函数移至 training_configs/common.py，具体数据、路径、统计与 prompt 设置直接放进各实验文件的 build_dataset()。两个基准实验保留原数据语义和路径覆盖变量，个人模板改为独立组合，不导入基准或他人的实验。

当时 experiments/baselines/ 与 template/ 集中管理参考示例，启动器只按指定模块调用一个 build_config()，不遍历其他实验。当前布局已按下方任务分组调整。
