## 2. 经本地电脑导出到 `user@192.168.10.202`

本机无法直连该内网 IP；本地电脑在同一局域网，可用 SSH 反向转发让源服务器的 `rsync` 经本地电脑到达目标。此前 `gitlab.litchibot.top` 也解析到 `192.168.10.202`，务必先在**本地电脑**确认 `user@192.168.10.202` 确实是获准存放权重的目标主机，并确认目标路径有至少 250 GB 可用空间。下面的 `user`、`/home/user/pi05-handover` 和 `<源服务器SSH别名>` 按实际账号、可写目录及 SSH 配置替换。目标应有 `rsync`，并使用 SSH 主机密钥核对目标身份。

在**本地电脑终端 A**检查目标：

```bash
ssh user@192.168.10.202 'hostname; command -v rsync; df -h /home/user'
ssh-keygen -F 192.168.10.202 | ssh-keygen -lf -
```

在**本地电脑终端 B**开启通道，传输期间保持运行：

```bash
ssh -N -T -o ExitOnForwardFailure=yes \
  -R 127.0.0.1:18022:192.168.10.202:22 <源服务器SSH别名>
```

以下在**源服务器**执行。首次连接目标时对照终端 A 看到的 SSH 主机密钥指纹，不跳过校验。先传全部历史 checkpoint、基础权重、数据和统计；`rsync` 中断后可重复同一命令续传，不经本地电脑落盘。

```bash
cd /home/zhiwei/workspace/code/pi05
RUN=/home/zhiwei/pi05-runtime
EXP=tomato_all_full_fullft_30hz_s42_run01
DEST=/home/user/pi05-handover
REMOTE=user@127.0.0.1
RSH='ssh -p 18022 -o HostKeyAlias=pi05-archive-192.168.10.202'
SSH_CMD=(ssh -p 18022 -o HostKeyAlias=pi05-archive-192.168.10.202)

"${SSH_CMD[@]}" "$REMOTE" 'hostname; df -h /home/user; command -v rsync'

for rel in \
  "checkpoints/pi05_fr3_wuji_fulltask_fullft_30hz/$EXP" \
  openpi-cache/openpi-assets/checkpoints/pi05_base/params \
  data/tomato_all_full_v1 \
  assets/tomato_all_full_v1_30hz; do
  "${SSH_CMD[@]}" "$REMOTE" "mkdir -p '$DEST/$rel'"
  rsync -a --partial --append-verify --info=progress2 -e "$RSH" \
    "$RUN/$rel/" "$REMOTE:$DEST/$rel/"
done

"${SSH_CMD[@]}" "$REMOTE" "mkdir -p '$DEST/logs' '$DEST/wandb'"
rsync -a --partial -e "$RSH" \
  "$RUN/tomato_all_full_fullft_30hz_s42_run01-launcher.log" \
  "$REMOTE:$DEST/logs/"
rsync -a --partial -e "$RSH" \
  logs/tomato_all_full_fullft_30hz_s42_run01_20261010_204247_2005930.log \
  "$REMOTE:$DEST/logs/"
rsync -a --partial -e "$RSH" \
  wandb/offline-run-20261010_204312-tfnd6rbk \
  "$REMOTE:$DEST/wandb/"
```

最后两条源文件位于仓库根目录。如果只需后续新阶段训练和部署，可只传 `60152/`、`reproducibility/`、`wandb_id.txt`、基础权重、数据与统计；保留全部历史检查点才能保留每万步的回退点。

传输后在源服务器对上述四个 `rel` 逐一做**内容校验**；无文件差异输出且退出码为 0 才算校验通过。此检查需重读全部文件，可能耗时：

```bash
for rel in \
  "checkpoints/pi05_fr3_wuji_fulltask_fullft_30hz/$EXP" \
  openpi-cache/openpi-assets/checkpoints/pi05_base/params \
  data/tomato_all_full_v1 \
  assets/tomato_all_full_v1_30hz; do
  rsync -a --checksum --dry-run --itemize-changes -e "$RSH" \
    "$RUN/$rel/" "$REMOTE:$DEST/$rel/"
done
```

目标上再检查 `60152/{params,train_state,assets}`、审计目录和 `df -h`。**迁移、内容校验和新服务器实际加载成功之前，不删除源机器权重。**本文仅给导出命令，没有执行传输或清理。

在迁移验收后，若确实要回收源服务器根盘空间，可在**源服务器**再次确认下列两个绝对路径并分别删除；这会清除全部历史回退点和本地基础权重，无法从源机器恢复：
