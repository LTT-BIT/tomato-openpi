## 部署对应的英文 prompt

权威文本保存在 `docs/prompts_1002_subtasks.json`，训练 metadata 与部署客户端使用同一文本。

| task_index | 中文含义 | 英文 prompt |
|---|---|---|
| 0 | 右手抓住盘子上的番茄串并握稳 | `Grasp the tomato truss on the plate with the right hand and hold it securely.` |
| 1 | 右手提起，移到双手中央并继续握住，供左手摘取 | `Lift the tomato truss with the right hand, move it to the center between both hands, and hold it steady for the left hand to pick a tomato.` |
| 2 | 左手从右手握住的番茄串上摘下一颗 | `Pick a single cherry tomato from the truss held by the right hand using the left hand.` |
| 3 | 左手将摘下的番茄放入左侧果盘 | `Place the picked cherry tomato into the plate on the left with the left hand.` |

第二个子任务已由用户确认：继续握住，不在中央松手。第四个子任务负责放置；不要把第三、第四个指令合并后输入单个子任务。

详细文字是训练标签，不能保证单凭“securely”获得抓取力控制。实际表现仍需实机评估。
外部控制程序负责判断子任务完成并切换 prompt；新指令不应直接替换旧 checkpoint 的训练语义。

## 启动训练并实时上传 W&B

当前环境已存在 W&B 登录凭据，不将凭据写入脚本或 Git。

```bash
cd /home/descfly/workspace/Pi05
WANDB_MODE=online bash scripts/train_fr3_wuji_1002_subtasks_detailed_30hz.sh
```

启动脚本已包含 `--wandb-enabled`，项目为 `openpi`。stdout/stderr 同时保存到
`logs/1002_subtasks_detailed_日期_时间_PID.log`，网络正常时指标实时上传，无需另开上传进程。
默认不覆盖已有 checkpoint。确需断点续训时在命令末尾加 `--resume`。

```bash

.venv/bin/wandb sync wandb/offline-run-实际时间和ID
```
