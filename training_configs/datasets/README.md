# 数据配置目录

这里保存训练数据的描述，不保存数据集、视频或归一化文件本身。实验配置选择一个 Dataset，本体适配器将它转换为训练框架的数据配置。

| 字段 | 含义 |
| --- | --- |
| version / repo_id | 数据版本与稳定身份 |
| root | 本机已经准备好的 LeRobot 数据目录 |
| sources | 原始来源或合并来源，用于溯源 |
| assets_dir / asset_id | 对应归一化统计的父目录与子目录 |
| expected_norm_sha256 / expected_norm_audit_sha256 | 文件摘要或归一化对象审计摘要，二者分别记录 |
| prompt_example | 英文任务示例；训练仍从数据 task 读取真实指令 |

当前有两份独立的 v1 数据描述：

- `tomato_fr3_fulltask_v1.py`：完整任务数据，占位路径，需先准备真实数据及统计。
- `tomato_fr3_all_full_v1.py`：三套完整任务数据的合并版本，保留原数据身份和统计审计摘要。

按数据内容命名，不与 LoRA 或全参方案绑定。同一数据可以被不同训练方案引用；来源、筛选、prompt 或变换发生变化时创建新的数据版本和对应统计。只迁移相同内容的本机路径时修改环境变量即可。

具体环境变量和准备步骤见 [训练使用说明](../../docs/训练使用说明.md)。
