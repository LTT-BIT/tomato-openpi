# 铲柠檬训练说明

安装、数据校验、统计、日志与续训见 [仓库 README](../../../README.md)，个人配置和协作规则见 [多人开发 README](../../../多人开发README.md)。

## 当前状态

目前仅建立任务目录，`baseline/` 和 `template/` 均为空，只有 `.gitkeep` 用于让 Git 保留目录。尚未定义本任务的本体、动作维度、数据集或训练配置，不能直接启动训练；未完成数据准备、正式训练或实机验证。

## 补充 baseline 时需要记录

- 本体、关节维度和顺序、动作语义、单位、相机映射、频率与 horizon。
- 数据生产来源、稳定版本和 repo_id、仓库内 `data/` 路径。
- `assets/` 下独立的统计身份，以及配套 `norm_stats.json` / `norm_metadata.json`。
- 配置名称、唯一实验名称、公共 recipe 版本和实际英文 task；prompt 示例不能替代数据中的真实指令。
- dry-run、数据与统计 check 的结果，以及准备完成、训练完成和实机验证各自的状态。

确认以上定义后再添加 `baseline/` 配置。后续实验从本任务 baseline 复制到 `template/<负责人>/`，每人独立文件，公共模型与训练流程继续复用。
